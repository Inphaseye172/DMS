## Known risks and items to confirm on Windows

1. **SDK signature drift.** `plugin/ae` was written from SDK knowledge and compiled only against the mock. Expect a few compile fixes against the real 2025/2026 SDK, centralized in `plugin/ae/ae_includes.h`. In particular, check the suite versions, `PF_ADD_*` macro arguments, the `PF_GPUDeviceSuite1` member names and `PF_REGISTER_EFFECT_EXT2`.
2. **Point parameter units.** Guided points are assumed to arrive already scaled for downsampling. Check at 1/2 and 1/4 resolution.
3. **SmartFX output origin.** The output world is assumed to start at `result_rect.left/top` in layer space. Verify with a cropped or transformed layer.
4. **`CUDA_MEMCPY2D` layout and context** in the GPU path (`plugin/ae/DMS_Depth_GPU.cpp`). This is the CUDA Driver API v2 layout. After Effects is assumed to make its CUDA context current on GPU render threads.
5. **CUDA EP `use_tf32` option name** (ORT 1.22). If ORT rejects it, session creation fails and the FP16→FP32 rung recovers.
6. **A foreign `onnxruntime_providers_shared.dll`** already loaded in the host could bind by name. We pre-load ours first, and conflicts are logged.
